# Customer Purchasing Behavior Analysis Using Python

## 📌 Project Overview

This project analyzes customer purchasing behavior using Python. The analysis explores customer demographics, annual income, purchase amounts, loyalty scores, purchase frequency, and regional distribution.

The project uses data analysis and visualization techniques to identify patterns and relationships in customer purchasing behavior.

## 🎯 Objectives

- Analyze customer demographics
- Understand annual income distribution
- Analyze customer purchase amounts
- Study customer loyalty scores
- Analyze purchase frequency
- Compare customer distribution across regions
- Identify relationships between income, purchases, loyalty, and purchase frequency
- Generate useful business insights

## 📊 Dataset

The dataset contains 238 customer records and 7 variables:

- User ID
- Age
- Annual Income
- Purchase Amount
- Loyalty Score
- Region
- Purchase Frequency

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Analysis Performed

- Data exploration
- Data quality checking
- Statistical analysis
- Customer age distribution
- Regional customer distribution
- Annual income distribution
- Purchase amount distribution
- Loyalty score distribution
- Purchase frequency distribution
- Annual income vs purchase amount analysis
- Loyalty score vs purchase amount analysis
- Correlation analysis
- Correlation heatmap

## 🔍 Key Findings

The analysis identified strong positive relationships among several customer attributes. In particular, purchase amount showed a very strong positive relationship with loyalty score and purchase frequency.

The analysis demonstrates how customer data can be explored and visualized to understand purchasing patterns and generate business insights.
